One program, one funny line: the hopeless tech support agent's reply to a
desperate customer, written for the make.fun bounty
["Have You Tried Turning It Off?"](https://make.fun/c/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

## The entry

> Good news — I've escalated you to Tier 2. Bad news — Tier 2 is me again, but with a fancier headset.

100 characters, one line. The escalation every desperate customer dreams of:
the same agent, upgraded only in headset.

## Run it

```sh
node main.ts
```

Requires Node 22+. Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`) and validates it is 1–199 characters first.
